How it works

  1. The selected rectangle is cropped from the image (and mirrored if a flip option is on), and each pixel is converted to its HSL lightness, (max(R,G,B) + min(R,G,B)) / 2, from 0 to 1. Brighter pixels are higher.
  2. Each pixel becomes a vertex of the front surface, raised by lightness × depth range. With Invert depth on, (1 − lightness) is used instead, so dark pixels become high.
  3. A flat back plane is placed base thickness below the lowest point, and side walls join it to the front, so the result is a single closed solid you can 3D print.
  4. All coordinates are divided by the DPM value, which sets the overall scale of the model.
